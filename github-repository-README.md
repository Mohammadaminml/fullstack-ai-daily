## About This Repository

`fullstack-ai-daily` is a growing collection of concise tutorials, practical examples, exercises, and cheat sheets for developers who want to strengthen both **Full-Stack Development** and **Artificial Intelligence** skills.

Every daily lesson is designed to be:

- Practical and applicable to real-world projects
- Short enough for consistent daily learning
- Supported by runnable code examples
- Reinforced through exercises and quick-reference cheat sheets
- Organized in a clean, date-based structure

## What You Will Learn

### Full-Stack Track

- HTML, CSS, and responsive design
- JavaScript and TypeScript
- React and Next.js
- C# and ASP.NET Core
- RESTful API design and integration
- SQL Server and database optimization
- Authentication, authorization, and security
- Testing, Git, Docker, and software architecture

### AI Track

- Python for AI development
- Machine Learning fundamentals
- Large Language Models (LLMs)
- Prompt Engineering
- Embeddings and Vector Databases
- Retrieval-Augmented Generation (RAG)
- AI Agents and tool calling
- AI evaluation, safety, and security
- Integration of AI capabilities into Full-Stack applications

Each date contains two independent learning paths:

- `full-stack/` — Modern frontend, backend, database, DevOps, and architecture topics
- `ai/` — Practical AI concepts, implementations, and Full-Stack integrations

## Learning Roadmap

For the best results, follow this workflow for each lesson:

1. Read the lesson's `README.md`.
2. Run and modify the code inside `examples/`.
3. Review the key concepts in `CHEATSHEET.md`.
4. Complete the exercises in `EXERCISES.md`.
5. Build a small variation of the example without copying the original code.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/fullstack-ai-daily.git
cd fullstack-ai-daily
```

Open the latest date folder and select either the Full-Stack or AI track. Runtime requirements and execution commands are documented inside each lesson.
